# 🐉 Pokémon Telegram Bot ⚡

🤖 **Pokémon Telegram Bot** — это Telegram-бот, с помощью которого можно узнавать информацию о покемонах, кормить их и устраивать бои прямо в чате!

Проект создан в учебных целях и показывает работу с Telegram Bot API, логикой игры и взаимодействием с пользователем.

---

## ✨ Возможности бота

✅ Получение информации о покемонах  
✅ Кормление покемонов 🍎  
✅ Бои между покемонами ⚔️  
✅ Ответы с эмодзи и понятным текстом  
✅ Управление через команды Telegram
